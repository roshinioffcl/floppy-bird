# 🐦 Floppy Bird

A lightweight browser-based Floppy Bird game built using HTML, CSS, and JavaScript Canvas.

## 🎮 Gameplay

Navigate the bird through obstacles by flapping and avoid colliding with pipes or the ground.

## ✨ Features

- Gravity-based bird movement
- Tap, click, or keyboard controls
- Procedurally generated pipe obstacles
- Collision detection
- Score tracking
- High-score persistence using LocalStorage
- Restart functionality
- Responsive browser-friendly canvas

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Canvas API
- LocalStorage

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/floppy-bird.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Controls

- **Space / Arrow Up** — Flap
- **Mouse click** — Flap
- **Touch** — Flap
